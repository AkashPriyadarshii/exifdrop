What sharing really sends

Your photo carries a folder of data it never shows you

GPS coordinates
Street-level location of where the shot was taken.
Camera and lens
Make, model and lens of the device that took it.
Timestamp
Exact date and time, to the second.
XMP and software
Editing history and device software tags.
PDF side
Author, creator tool, and edit history.

Most apps carry the metadata through. WhatsApp document mode, email attachments and Telegram file transfer forward the tags intact.

ExifDrop reads the file as binary, edits the metadata segments, and copies the pixels untouched. A wipe does not touch image quality.

What it strips

Lossless by design

Images wiped clean

JPEG, PNG, WebP. The stripper edits the EXIF and XMP segments in place, then copies pixels untouched. No quality loss, no resize.

PDFs neutralized

The trailer Info dictionary and the XMP metadata stream are cleared in place. Pages, text and layout stay intact.

Offline by construction

No INTERNET permission. The file never leaves the device, nothing is uploaded, nothing is logged.

Names don't leak either

Default output is share_<hash>.jpg. The IMG_20250115_140233.jpg date pattern does not survive. Keeping the original name is an opt-in.
